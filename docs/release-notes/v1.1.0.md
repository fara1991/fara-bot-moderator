## FaraBotModerator v1.1.0

ポケモン対戦向けのチャットコマンドと、ポケモンのサイトとの登録データの共有を追加しました。あわせて、設定ファイルが壊れにくくなり、.NET 10 に更新しました。

### 新機能
- **ポケモンのチャットコマンド（`!poke`）を追加しました。**
  - ダメージ計算、努力値の推定、素早さの計算・比較ができます。
  - 自分のポケモンとチームを登録できます。チームの番号は、シングルとダブルで別々に管理されます。
  - 相手のポケモンの振り方・性格・持ち物・技などを、覚えさせて使えます。履歴も確認できます。
- **設定画面に「Game」タブを追加しました。**（Translate / Game / Timer の 3 つ）
  - ポケモンの設定は、このタブにまとめました。
  - 登録したポケモンとチームを、別ウィンドウで確認できます。
  - ポケモンのデータの取得元（本番か確認用か）を、画面で選べます。
- **ポケモンのサイトとの登録データの共有に対応しました。**
  - サイトで登録したデータを、アプリのコマンドで使えます。
  - アクセスキーの作り直しにも対応しました。作り直しの間の登録は消えません。

### 安定性の改善
- 設定ファイル（`secrets.json` など）の保存に失敗しても、設定が消えにくくなりました。ファイルが壊れていたときは、中身を残したまま退避して、初期値で起動します。
- Twitch の接続が止まる、アプリが落ちる、エラーが見えなくなる、といった不具合を直しました。
- 認証まわりを直しました。認証の戻りを二重に処理しない、認証に失敗した後で認証画面を開き直さない、通信に失敗しても認証画面を開かない、などです。
- 正規表現の変換が時間切れになったときや、Beat Saber の設定が読めなかったときの動きを直しました。

### 変更
- **Twitch の権限を、使っている機能に必要なものだけにしました。**（`channel:moderate` を外しました）
  - 更新後に、Twitch の認証をやり直す必要が出る場合があります。画面の案内に従って、もう一度「Authorize」を押してください。
- **.NET 10 に更新しました。** .NET のランタイムはインストーラーに同梱されているので、別にインストールする必要はありません。
- 上書きインストールしても、設定ファイルを上書きしないようにしました。
- Reaction Event Settings の説明文の誤記（`{followedName}` → `{followerName}`）を直しました。
- 使い方の資料（[README](https://github.com/fara1991/fara-bot-moderator#readme) と `docs/`）をスクリーンショット付きで整えました。
