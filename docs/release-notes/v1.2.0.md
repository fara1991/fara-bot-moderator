## FaraBotModerator v1.2.0

Bits の累計の表示と、ウィンドウの大きさの変更に対応しました。あわせて、Twitch との通信を自前の実装に置き換え、設定ファイルなどの保存先を移し、安定性を改善しました。

### 新機能
- **Bits の累計（`{totalBitsAmount}`）を使えるようにしました。** Bits の通知のメッセージに入れられます。
- **ウィンドウの大きさを変えられるようにしました。**
  - 大きさに合わせて、Main Settings の WebView（Twitch のページなどを表示する内蔵ブラウザ）も広がります。
  - 画面が小さい PC（幅 1500px 未満など）では、起動時に最大化します。
- **接続の状態の表示を見やすくしました。** つなぎ直している間は「Reconnecting...」と表示し、切断中と見分けられます。
- Twitch の認証が終わったら、WebView に結果のページを表示するようにしました。認証の戻りで、接続エラーのページが一瞬出なくなりました。

### 変更
- **設定・ログ・WebView のデータの保存先を、`%LOCALAPPDATA%\FaraBotModerator` に移しました。**
  - インストール先（`Program Files`）には、書き込まなくなりました。インストール先の「全ユーザーの書き込み権限」も外しました。
  - 以前の保存先にあった設定ファイルやログは、初回の起動で自動的に移します。
  - **WebView のデータ（Twitch のログイン状態など）は引き継がれません。** 更新後に、Twitch のサイトへのログインをやり直してください。
  - 更新後に、Twitch の認証をやり直す必要が出る場合があります。画面の案内に従って、もう一度「Authorize」を押してください。
- **Twitch との通信を、メンテナンスされていない TwitchLib を使わない、自前の実装に置き換えました。** API・EventSub（Follow などの通知）・チャットのすべてが対象です。使い方は変わりません。
- 「アプリ」の一覧に出る名前に、バージョンが付かないようにしました。起動中は、インストール・アンインストールを止めるようにしました。
- イベントごとの有効（チェックボックス）が、通知に効くようにしました。

### 安定性の改善
- 設定ファイルの読み込みに失敗したまま保存して、空の値で上書きしないようにしました。
- 定期・日時指定のメッセージが、1 回の失敗で止まらないようにしました。日時指定の日時は、地域設定に依らない形で保存します。以前の形のファイルも、そのまま読めます。
- 回線が切れたときに早く気づいて、つなぎ直せるようにしました。
- 翻訳（DeepL）の失敗を、視聴者のメッセージのたびにチャットへ出さないようにしました。同じ理由の通知は 5 分に 1 回までで、理由に合った文で知らせます。
- 棒読みちゃんの確認が一時的に失敗しただけでは、切断しないようにしました（続けて失敗したときだけ切ります）。
- 通知のメッセージに特定の文字の並び（`\u003C` など）が入っていると、設定ファイルが壊れたものとして扱われることがある問題を直しました。
- チャットウィンドウの行が増え続けないようにしました（1000 行まで）。
- ブラウザを開けないとき、クリップボードを使えないとき、Twitch のユーザー名が正しくないときに、アプリが止まらないようにしました。
