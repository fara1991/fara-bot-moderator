# コマンド早見表

チャットで使えるコマンドの一覧です。コピーして使えます。詳しい説明は、各ページへのリンクから見てください。

「使える人」の「全員」は視聴者を含みます。「配信者・モデレーター」は、配信者本人とモデレーターのみです。「記載なし」は、操作説明書に使える人の制限が書かれていないものです。

## ポケモン（!poke）

接頭辞は `!pokech`（ポケモンチャンピオンズ）・`!pokesv`（スカーレット・バイオレット）・`!pokess`（ソード・シールド）・`!poke`（チャンピオンズ扱い）です。以下は `!pokech` の例です。詳しくは [ポケモンのコマンド](pokemon.md) を見てください。

| コマンド | 説明 | 例 | 使える人 |
|---|---|---|---|
| `!poke help` | 使えるコマンドの一覧を返す | `!poke help` | 全員 |
| `add -m` | 育成済みポケモンを登録 | `!pokech add -m ガブリアス 4 32 0 0 0 30 ようき` | 配信者・モデレーター |
| `set -m` | 登録済みの育成ポケモンを更新 | `!pokech set -m 1 H32 B32` | 配信者・モデレーター |
| `ls -m` / `detail -m` | 育成ポケモンの一覧 / 詳細 | `!pokech ls -m` | 全員 |
| `rm -m` | 育成ポケモンの削除 | `!pokech rm -m 1` | 配信者・モデレーター |
| `add -t` | チームにポケモンを追加 | `!pokech add -t 1 1 こだわりスカーフ` | 配信者・モデレーター |
| `use -t` / `unuse -t` | 使用チームの切り替え / 解除 | `!pokech use -t 1` | 配信者・モデレーター |
| `ls -t` / `detail -t` | チームの一覧 / 詳細 | `!pokech ls -t` | 全員 |
| `rm -t` | チームの削除 | `!pokech rm -t 1` | 配信者・モデレーター |
| `set -t` | チームを別の形式へ移す | `!pokech set -t 2 ダブル 5` | 配信者・モデレーター |
| `format` | 登録している対戦形式の確認 | `!pokech format` | 全員 |
| `format set` / `format clear` | 対戦形式の登録 / 解除 | `!pokech format set ダブル` | 配信者・モデレーター |
| `dmg` | ダメージ計算 | `!pokech dmg ガブリアス ドラゴンクロー+1 リザードン` | 全員 |
| `faster` | 素早さ比較 | `!pokesv faster ガブリアス ハバタクカミ` | 全員 |
| `scan` | 受けたダメージから相手の振り方を推定 | `!pokech scan 攻撃 技±ランク 相手 受けたダメージ` | 配信者・モデレーター |
| `add -r` / `set -r` | 対戦中の相手の登録 / 更新 | `!pokech add -r カイリュー` | 配信者・モデレーター |
| `ls -r` / `detail -r` | 対戦中の相手の一覧 / 詳細 | `!pokech ls -r` | 全員 |
| `rm -r` / `clear -r` | 相手の取り消し / 全員解除 | `!pokech clear -r` | 配信者・モデレーター |
| `end` | 試合を終えて、相手を履歴に移す | `!pokech end` | 配信者・モデレーター |
| `ls -h` / `detail -h` | 試合の履歴の一覧 / 詳細 | `!pokech ls -h` | 全員 |
| `rm -h` | 履歴の削除 | `!pokech rm -h 1` | 配信者・モデレーター |

> [!NOTE]
> 登録系のコマンドには、アクセスキーが必要です。設定は [ポケモンのコマンド](pokemon.md#データ共有アクセスキー) を見てください。

## Beat Saber

詳しくは [Beat Saber のコマンド](beatsaber.md) を見てください。

| コマンド | 説明 | 例 | 使える人 |
|---|---|---|---|
| `!bsr XXX` | 曲をリクエスト（外部のソングリクエスト用ボットが処理） | `!bsr XXX` | 記載なし |
| `!bomb [位置]` | 爆弾を 1 個出す（1〜12。省くとランダム） | `!bomb 5` | 記載なし |
| `!bombline [位置]` | 同じ位置に、爆弾を 5 個の列にして出す | `!bombline 3` | 記載なし |
| `!bombreset [位置]` | 上段か下段の 4 か所に、同時に爆弾を出す | `!bombreset 9` | 記載なし |

> [!NOTE]
> `!bomb` 系は、Mod（FaraBombRush）の Play Mode が「Interactive」のときに使えます。
