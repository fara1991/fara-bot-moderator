# よくある質問

起動できない・チャットが取得できない・翻訳や読み上げが動かない、などのときの確認項目です。直らないときは [困ったとき](troubleshooting.md) も見てください。

## 起動時にエラーが発生します

次を確認してください。
- .NET 8.0 ランタイムがインストールされているか
- WebView2 ランタイムがインストールされているか
- ウイルス対策ソフトにブロックされていないか

## チャットが取得できません

- AccessToken の有効期限が切れていないか（「Main Settings」で確認）
- 「Authorize」ボタンから再認証を試す
- `UserName` が正しく設定されているか

## 翻訳が動作しません

- DeepL API キーが正しく入力されているか
- DeepL API の月間使用量が上限に達していないか
- インターネット接続が正常か

## 棒読みちゃんで読み上げられません

- 棒読みちゃんが起動しているか
- 棒読みちゃんの HTTP 連携が有効か（ポート 5008）
- `BouyomiChanConnect` にチェックが入っているか
- Twitch に接続する前に、棒読みちゃんを起動しているか

## イベント通知が届きません

- 各イベントのチェックボックスが ON になっているか
- Twitch に正常に接続されているか（`State: Connect`）
- 「Test Send」ボタンでテスト送信を試す

## 設定が保存されません

アプリ終了時に自動で保存されます。設定は `Resources\secrets.json` ファイルに保存されます。

## 起動時に「secrets.json が壊れていた」と表示されました

壊れたファイルは、中身を消さずに `secrets.broken-日時.json` という名前で `Resources` フォルダに残します。設定は初期値で作り直しています。

退避したファイルを開いて、必要な設定（Twitch の接続・API キーなど）を入れ直してください。
